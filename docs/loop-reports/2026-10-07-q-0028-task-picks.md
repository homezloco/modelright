# Task Picks (/pick & /pick/[task]) Implementation (q-0028)

## Acceptance Criteria
- `/pick` and `/pick/[task]` pages for tasks: `chat`, `coding`, `long-context`, `vision`, `cheap-bulk`.
- Each category ranks models by an explicit rule written on the page:
  - `long-context`: context window >= 200,000 tokens, sorted by input price per 1M ascending.
  - `vision`: has image input (modality tags include vision or image), sorted by output price per 1M ascending.
  - `cheap-bulk`: input price <= $0.50 / 1M tokens, sorted by input price per 1M ascending.
  - `chat` and `coding`: available paid models from top five most-listed active providers, sorted by output price per 1M ascending.
- Displays top 10 models per task.
- Each row links to model detail (`/models/[provider]/[slug]`) and compare (`/compare?m=[provider]/[slug]`).
- Unit tests verify each task's ranking rule against a fixture list.

## What Changed
1. `src/lib/picks.ts`: Defined task rules, filter/sort logic, and types for `TASK_RULES`.
2. `src/app/pick/page.tsx`: Index page listing all task pick categories with descriptions, rules, and navigation links.
3. `src/app/pick/[task]/page.tsx`: Dynamic task pick route rendering the explicit rule box, top 10 table, and links to Detail and Compare.
4. `tests/unit/picks.test.ts`: Vitest unit tests verifying ranking and filtering rules for all 5 task categories against fixture models.
